# cardsplan/

Imagens de exemplo retiradas da internet, usadas apenas como entrada de teste
manual do leitor de cartão de plano de saúde (OCR em `api/read-card.ts`).

- Os dados visíveis (nomes, números, validades) são **fictícios** — não
  correspondem a titulares reais.
- Nenhuma destas imagens é referenciada pelo código ou pelos testes
  automatizados; servem de fixture manual durante o desenvolvimento.
- Não use cartões reais aqui: este repositório é público e dado de plano de
  saúde é dado sensível (art. 11 da LGPD).
